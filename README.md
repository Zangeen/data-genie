# 🤖 Data Genie

AI-powered Business Intelligence Assistant built with Python, Pandas, Streamlit, LangChain, and Groq.

## Features

- 📊 Business Intelligence dashboard
- 💰 Total revenue analysis
- 🏙️ Revenue by city
- 📦 Revenue by product
- 🔎 City-based data filtering
- 🤖 AI chatbot for business questions
- 🛠️ LangChain tools for data analysis

## Technologies

- Python
- Pandas
- Streamlit
- LangChain
- Groq
- Python-dotenv

## How to Run

```bash
streamlit run app.py
